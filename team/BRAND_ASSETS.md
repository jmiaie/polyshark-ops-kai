## Brand Style Guide

### Color Palette
| Purpose | Color | Hex |
|---------|-------|-----|
| Primary Background | Dark | #0D1117 / #111827 |
| Card Background | Darker | #0a0e13 |
| Accent (Shark) | Teal/Blue | #1a8cff |
| Profit/Positive | Green | #00C853 |
| Loss/Negative | Red | #FF3B30 |
| Neutral | Amber | #FF9500 |
| Text Primary | White | #FFFFFF |
| Text Secondary | Gray | #8B949E |

### Typography
- **Primary Font:** Inter / SF Pro (system fonts for Telegram)
- **Headers:** Bold, 16-18px
- **Body:** Regular, 14px
- **Data/Numbers:** Monospace feel, bold

### Branding Elements
- Shark silhouette (subtle, not loud)
- "POLYSHARK" text or 🦈 emoji
- Clean borders using `───────────────────` dash lines
- Minimal emoji usage — intentional, not decorative

### Card Structure
```
🦈 POLYSHARK
───────────────────
[Market Question + Whale Badge]
[Direction Arrow + Outcome]
[Profit + ROI]
[WR Badge + Streak]
[30d WR + Trade Count]
[Size + Entry Price]
[Opened | Closes | Resolved]
[Link + Wallet]
───────────────────
⚡ Powered by Polyshark
```

## Design Notes for Future Assets
- Dark themes work best (reduces eye strain for 24/7 monitoring)
- High contrast text required (white on dark)
- Subtle branding > flashy (financial product, not casino)
- Shark motifs should be minimal — silhouette preferred
- Avoid: busy patterns, bright flashy colors, competing visual elements
